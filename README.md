# Astro 416 Final Project

## Repository Contents

This repository contains all the materials I used for my final project. 

- 'README.md' is this file, which describes all of the materials in my Github repository.

- 'final_project.ipynb' is a Jupyter notebook that contains all of the coding used to perform machine learning to replicate TESS results with the ideal combination of parameters.

- 'confirmed_exoplanets.csv' is a dataset taken from the exoplanet archive that contains different parameters for confirmed TESS exoplanet detections.

- 'TESS_exoplanet_candidates.csv' is also a dataset from the exoplanet archive that contains different parameters for every TESS exoplanet candidate.
